# 연구 주제 분류

연구 자료를 읽으며 반복되는 주제를 찾아 분류한다. 주제 분류는 파일을 옮기는 일만을 뜻하지 않는다. 한 자료에 여러 태그를 붙여 서로 다른 질문에서 다시 찾을 수 있게 한다.

## 첫 분류

자료 찾기, 기록 습관, 협업, 도구 사용이라는 임시 분야를 정한다. 각 자료의 중심 내용을 읽고 분야를 배정한다. 여러 주제에 걸치면 태그를 여러 개 남긴다.

## 기준 수정

비슷한 자료가 서로 다른 분야에 흩어졌는지 검색해 본다. 태그 표기를 맞추고 분류 이유를 메모한다. 분류 기준을 바꾼 날짜와 이유를 연구 기록에 남긴다.

## 연결

인터뷰와 관찰 기록이 같은 주제를 설명하면 연결한다. 공통 태그만으로 충분하지 않은 관계는 직접 이유를 적어 저장한다.

핵심 낱말: 연구, 주제, 분류, 태그, 검색, 연결, 인터뷰, 관찰

이 문서는 PKOS 지식맵 사용 연습을 위한 가상 자료이다.
