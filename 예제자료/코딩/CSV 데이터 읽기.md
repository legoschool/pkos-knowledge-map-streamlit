# CSV 데이터 읽기

CSV는 행과 열로 정리한 데이터를 글자로 저장하는 파일 형식이다. 파이썬으로 CSV를 읽으면 가계 기록, 관찰 기록, 설문 결과를 같은 방식으로 다룰 수 있다.

## 작은 예제

날짜, 분류, 금액의 세 열을 가진 가상 지출 데이터를 준비한다. 빈칸과 숫자 형식을 점검한 뒤 분류별 합계를 구한다.

## 처리 순서

파일 열기 → 열 이름 확인 → 행 반복 → 값 정리 → 합계 계산 → 결과 저장

반복 처리에서는 각 행을 같은 규칙으로 읽는다. 금액이 비어 있거나 숫자가 아닌 경우에는 오류 위치를 기록하고 나머지 데이터를 계속 처리한다.

## 다음 활동

분류별 합계를 막대그래프로 시각화한다. 원본 데이터와 계산 결과를 따로 저장하면 오류가 생겼을 때 비교하기 쉽다.

핵심 낱말: CSV, 데이터, 파이썬, 반복, 분류, 가계, 시각화
