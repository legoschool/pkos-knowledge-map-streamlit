# 그래프 시각화 기초

그래프 시각화는 대상을 점으로, 관계를 선으로 표현한다. 지식맵에서는 문서가 점이 되고 공통 태그나 직접 정한 관계가 선이 된다.

## 작은 데이터부터

문서 여섯 개와 태그 세 개로 시작한다. 각 문서에 고유한 식별자를 부여하고, 연결할 두 문서의 식별자와 연결 이유를 저장한다.

## 읽기 쉬운 지도

분야마다 색을 다르게 쓰고 문서의 제목을 표시한다. 자료가 많아지면 분야 필터와 검색으로 범위를 줄인다. 화면에서 가까운 점이 반드시 의미가 더 비슷한 것은 아니므로 연결 이유를 따로 보여 준다.

## 결과 설명

시각화는 발표와 연구 결과를 이해시키는 도구다. 선의 개수가 많다는 이유만으로 지식의 질이 좋아졌다고 해석하지 않는다. 필요한 자료를 찾는 데 도움이 되는지 확인한다.

핵심 낱말: 그래프, 시각화, 태그, 연결, 검색, 분야, 연구, 발표

이 문서는 PKOS 지식맵 사용 연습을 위한 가상 자료이다.
