문서에 흩어져 있던 생각을 한눈에 살펴보는 도구입니다. 예제로 먼저 연습한 뒤 자기 자료를 넣고, 분야와 메모를 고쳐 나만의 정리 방식을 완성해 보세요.

가상 예제 16개파이썬 + Streamlit온라인 / 내 컴퓨터 실행
예제로 시작내 자료 넣기결과 보관내 컴퓨터 실행문제 해결직접 배포

민감한 자료는 내 컴퓨터에서 실행하세요.

온라인 앱에서 파일을 선택하면 자료가 운영 서버로 전송됩니다. 지도 만들기 버튼을 누르기 전에도 업로드됩니다. 학생 정보, 비공개 업무 문서 등은 내 컴퓨터 실행 방법을 이용하세요.

개인정보 자동 가림은 완벽하지 않습니다. 올리기 전 원자료를 가리는 기능도 아닙니다. 공개 소스와 예제에는 실제 개인 자료를 포함하지 않았습니다.

01 · 처음에는 예제부터

네 단계면 첫 지식맵이 완성됩니다.

STEP 1예제 열기
STEP 2문서 살펴보기
STEP 3분류·메모 수정
STEP 4결과 내려받기
1

예제 16개로 시작하기

앱의 1 · 자료 넣기에서 예제 16개로 시작을 누릅니다. 예제는 실습용으로 만든 가상 문서입니다. 자기 파일 없이도 전체 과정을 연습할 수 있습니다.

처리 중에는 기다려 주세요. 완료되면 문서와 분야, 연결을 볼 수 있습니다.

2

지도와 문서를 함께 보기

2 · 살펴보고 정리로 갑니다. 분야를 고르거나 검색어를 넣고, 자세히 볼 자료 선택 상자에서 문서를 고르세요. 추출된 본문과 태그, 연결된 문서를 함께 확인합니다. 지도는 확대·이동하거나 점 위에 마우스를 올려 살펴봅니다.

자동 연결은 단어를 바탕으로 계산한 제안입니다. 두 자료가 실제로 어떤 관계인지 읽으면서 판단해 보세요.

3

자기 기준으로 고치기

선택한 문서의 제목·분야·태그·메모를 고치고 수정 저장을 누릅니다. 연결하고 싶은 다른 문서는 직접 연결 추가로 이어 보세요.

예: 분야를 ‘다음 수업 준비’로 바꾸고, 메모에 ‘다음 활동에 적용해 볼 아이디어’라고 적어 보세요.

4

컴퓨터에 내려받기

3 · 내려받기에서 내려받을 파일 준비를 누릅니다. 필요한 형식의 다운로드 버튼을 눌러 저장하세요.

먼저 HTML 지도 하나를 받아 브라우저에서 열어 보세요. 작업 결과가 파일로 남았는지 직접 확인할 수 있습니다.

02 · 내 자료로 해 보기

작은 묶음으로 시작하세요.

  1. 현재 결과를 내려받은 뒤 자료 지우고 처음으로를 누릅니다.
  2. 업로드 안내를 읽고 업로드 안내를 확인했습니다를 선택합니다.
  3. 허용되는 문서 몇 개 또는 ZIP 묶음을 선택합니다. 온라인에서는 이때 파일이 서버로 전송됩니다.
  4. 업로드한 자료로 지도 만들기를 누르고 완료를 기다립니다.
  5. 문서를 읽어 추출 상태를 확인한 뒤 분야·태그·메모를 수정합니다.

같은 실습을 다시 해 보고 싶다면 예제 ZIP을 받아 직접 업로드해 보세요.

가상 예제 16개 ZIP 받기

설명서만 따로 내려받았다면 예제 파일이 옆에 없을 수 있습니다. 온라인 예제 폴더에서 ZIP을 받거나 앱의 예제 버튼을 이용하세요.

웹판의 처리 기준 · MiB는 1,048,576바이트입니다.
항목기준
올리는 용량전체 50MiB 이하 · 파일 하나 20MiB 이하
압축 내부항목 하나 20MiB 이하 · 해제 누적 100MiB 이하 · ZIP 중첩 2단계까지
항목 수업로드와 ZIP·Office 압축 내부 항목을 합쳐 300개까지. 내부 디렉터리도 포함합니다.
그림과 스캔문서 속 그림을 추출·복사하지 않으며 OCR을 하지 않습니다. 그림 속 글자는 지식맵의 본문으로 읽지 못합니다.

DOCX·PPTX·XLSX·HWPX도 내부는 압축 구조입니다. 파일 수가 적어도 내부 항목이 많으면 제한에 걸릴 수 있습니다. 암호·손상·스캔 문서는 파일 선택이 가능해도 본문 추출이 실패할 수 있습니다.

03 · 결과를 내 것으로 보관하기

앱을 닫기 전에 다운로드하세요.

버튼받는 것과 쓰임
HTML 지도 받기브라우저로 열어 보는 오프라인 지도입니다. 읽기 전용이라 이 파일에서 수정할 수는 없습니다.
JSON 데이터 받기문서·분류·연결 정보를 보관하거나 다른 프로그램에서 분석할 때 씁니다.
정리 파일 ZIP 받기가림 처리된 Markdown, 지도, 편집 기록을 함께 받습니다. 올린 원본 파일은 포함하지 않습니다.

임시 작업 공간이라는 점을 기억하세요.

이 앱은 계정별 영구 보관함이 아닙니다. 초기화나 새 작업 교체, 세션 객체 정리, 서버 재시작으로 작업이 없어질 수 있습니다. 탭을 닫는 즉시 서버 파일이 삭제된다고 보장하지는 않습니다.

현재는 결과 JSON·ZIP을 다시 올려 같은 프로젝트를 복원하는 기능이 없습니다. 다시 시작할 때는 원자료로 새 지도를 만드세요. 원본 자료와 수정한 결과를 각각 보관해 주세요.

04 · 내 컴퓨터에서 사용하기

Windows에서는 설치 한 번, 실행 한 번입니다.

  1. Python 공식 사이트에서 Python을 설치합니다. 3.12 권장, 3.12 이상이 필요합니다. 설치 화면의 Add python.exe to PATH가 보이면 선택합니다.
  2. 프로그램 전체 ZIP을 내려받아 압축을 모두 풉니다. streamlit_app.py가 보이는 폴더를 엽니다.
  3. 설치.cmd를 더블클릭합니다. 필요한 패키지를 설치하므로 처음에는 인터넷이 필요합니다. 완료 메시지가 나올 때까지 기다립니다.
  4. 실행.cmd를 더블클릭합니다. 자동으로 창이 열리지 않으면 http://localhost:8501로 접속합니다.
  5. 작업하는 동안 실행 창을 열어 둡니다. 종료할 때는 실행 창에서 Ctrl+C를 누릅니다.

주소창이 localhost:8501이면 내 컴퓨터에서 실행 중인 앱입니다. 선택한 자료는 내 컴퓨터의 프로그램으로 전달됩니다. 공개 온라인 주소에 접속한 화면에서는 서버로 업로드됩니다.

이 Streamlit판을 로컬 실행

익숙한 웹 화면을 내 컴퓨터에서 사용합니다. 개별 20MiB·전체 50MiB 등의 제한과 임시 저장 방식은 그대로입니다.

기존 전체 로컬 버전 사용

큰 자료실의 폴더 전체를 정리하고 결과 폴더를 계속 관리할 때 사용합니다. 문서 속 그림 추출과 별도 준비가 필요한 OCR 옵션도 활용할 수 있습니다.

macOS·Linux / 터미널에서 실행하기

프로젝트 폴더에서 다음 명령을 실행합니다.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py --server.address=127.0.0.1

포트가 사용 중이면 마지막 명령에 --server.port=8502를 추가하고 http://localhost:8502로 접속합니다.

05 · 자주 만나는 상황

이럴 때는 이렇게 해 보세요.

설치가 끝나지 않거나 실행 창이 닫혀요.

Python 3.12 이상인지 확인하고, 압축을 모두 푼 폴더에서 설치.cmd를 다시 실행하세요. 인터넷 연결과 오류 메시지를 확인합니다. 설치가 끝나면 실행.cmd를 실행하세요.

용량이 작은데 업로드가 거절돼요.

Office 문서의 압축 내부 항목도 개수 제한에 포함됩니다. 파일 하나가 20MiB 이하인지, 전체가 50MiB 이하인지 확인하고 문서를 조금씩 나누어 넣어 보세요. 큰 자료실은 전체 로컬 버전에서 처리합니다.

사진이나 PDF에 글자가 있는데 본문이 없어요.

글자가 그림으로 저장된 자료는 OCR이 필요합니다. 웹판은 OCR을 하지 않으므로 텍스트가 들어 있는 PDF·문서로 다시 저장하거나 전체 로컬 버전의 OCR 옵션을 이용하세요.

문자나 표의 순서가 원본과 달라요.

글꼴과 문서 구조에 따라 추출 순서나 문자가 달라질 수 있습니다. 원문과 비교해 확인하세요. 자동 태그와 연결도 사용자가 검토하며 고칠 수 있습니다.

새로고침 뒤 작업이 사라졌어요.

세션이 바뀌면 임시 작업이 이어지지 않을 수 있습니다. 원자료로 지도를 다시 만들고 결과를 내려받아 보관하세요. 결과 ZIP을 다시 올려 프로젝트를 복원하는 기능은 현재 없습니다.

온라인 앱이 잠들었다는 화면이 보여요.

Community Cloud의 깨우기 버튼을 누르고 앱이 다시 시작될 때까지 기다립니다. 온라인 앱의 처리 자원과 상태에 따라 실행 시간이 달라질 수 있습니다.

06 · 내 온라인 앱으로 배포하고 싶다면

Render 또는 Streamlit Cloud에서 실행 주소를 만듭니다.

Render에서 간편하게 배포하기

Render에 배포하기

  1. 위 링크를 열고 Render에 로그인합니다.
  2. 서비스 이름 pkos-knowledge-map과 Free 설정을 확인하고 배포를 진행합니다. 저장소와 실행 설정은 자동으로 읽습니다.
  3. 상태가 Live가 되면 표시되는 https://…onrender.com 주소를 엽니다.
  4. 예제 16개로 시작을 눌러 확인한 뒤 주소를 공유합니다.

무료 서비스는 15분간 접속이 없으면 쉬었다가 다시 접속할 때 시작하므로 처음 열 때 약 1분 기다릴 수 있습니다. 재시작 시 임시 자료가 사라질 수 있어 결과는 내려받으세요. 공식 무료 서비스 안내

이 링크는 배포 시작용이며 실행 중인 앱 주소가 아닙니다. 자동 업데이트는 꺼져 있으므로 새 코드는 Render의 Manual Deploy에서 반영합니다.

GitHub 소스 저장소 · Streamlit 공식 배포 안내

공식 CLI에 Community Cloud 신규 배포 명령이 없어 위의 공식 화면 절차를 사용합니다. streamlit run은 프로그램을 실행하는 명령입니다. 실제 자료를 GitHub에 올릴 필요는 없습니다.

첫 실습이 끝났는지 확인해 보세요.

  • 예제 지도를 만들고 문서 하나를 열어 봤습니다.
  • 분야나 메모를 바꾸고 수정 저장을 눌렀습니다.
  • HTML 지도를 내려받아 브라우저에서 열어 봤습니다.
  • 자기 자료는 온라인 업로드와 내 컴퓨터 실행 중 알맞은 방법을 선택할 수 있습니다.
